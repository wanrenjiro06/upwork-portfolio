### Clone & Run Locally

```bash
git clone https://github.com/wanrenjiro06/upwork-portfolio.git
cd upwork-portfolio
```

**Run web projects locally:**
```bash

cd "Websites Portfolio/AI Writing Assistant"
python -m http.server 3000
```

Visit `http://localhost:3000` in your browser.
