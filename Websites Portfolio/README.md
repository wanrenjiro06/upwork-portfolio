# Web Design Portfolio — 3 Interactive Showcase Projects

A collection of three front-end design portfolio pieces showcasing modern web design, responsive layouts, and interactive features.

## Projects

### 1. Quillo – AI Writing Assistant
**Live:** https://quillo-ai-writer.netlify.app/

A SaaS landing page design for an AI writing assistant with:
- Animated gradient hero section with blob pulse animation
- Interactive FAQ accordion with smooth transitions
- Product mockup showcase with shimmer loading effects
- Scroll-reveal fade-up animations
- Fully responsive design (mobile, tablet, desktop)

**Tech Stack:** HTML5, CSS3, JavaScript, Intersection Observer API

---

### 2. Meridian Studio – Creative Agency Portfolio
**Live:** https://meridian-creative.netlify.app/

A minimal creative agency portfolio website featuring:
- Auto-scrolling logo marquee (pauses on hover)
- Smooth scroll-reveal animations on cards
- Interactive FAQ with animated chevron icons
- Gradient text effects and modern styling
- Glass-morphism design elements

**Tech Stack:** HTML5, CSS3, JavaScript, CSS Animations

---

### 3. Lumira – Fashion E-commerce
**Live:** https://lumira-apparel.netlify.app/

An interactive e-commerce interface design with:
- Animated gradient hero (orange → coral → pink)
- Working product filter system (category, size, availability)
- Dynamic banner that changes based on selected category
- Shopping cart with live counter and toast notifications
- Product grid with 14+ items, responsive layout
- Add-to-cart functionality with visual feedback

**Tech Stack:** HTML5, CSS3, JavaScript, DOM manipulation, Event listeners

## Getting Started

### Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/websites-portfolio.git
   cd websites-portfolio
   ```

2. **Run a local server:**
   - Using Python 3:
     ```bash
     python -m http.server 3000 --directory "AI Writing Assistant"
     ```
   - Or use Live Server extension in VS Code

3. **View in browser:**
   - Quillo: `http://localhost:3000/`
   - Meridian: `http://localhost:3001/`
   - Lumira: `http://localhost:3002/`
